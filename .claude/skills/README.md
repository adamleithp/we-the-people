# Skills

`integration-astro-static` is PostHog's Astro setup guide.

Everything else here is Emil Kowalski's skill set, copied unchanged from
[emilkowalski/skills](https://github.com/emilkowalski/skills) at `4061b67`
(MIT, see `LICENSE-emilkowalski`). To update them, copy `skills/*` from a
newer checkout over these folders.

`pick-ui-library`, `prototype` and `review-animations` only run when asked for
by name (`/review-animations`). `animate-expo`, `write-swift` and
`ask-sonner` are for React Native, Swift and the Sonner toast library, which
this site doesn't use; they're kept so the set matches upstream.
